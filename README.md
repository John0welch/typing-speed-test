## Typing Test Guide

This application helps users practice
their typing skills.

### Performance Measurements

- Words per minute (WPM)
- Typing accuracy
- Correct characters
- Incorrect characters

### How to Use

1. Start a typing session.
2. Read the displayed passage.
3. Type the text in the input area.
4. Review your performance results.

### Practice Recommendations

- Focus on accuracy first.
- Maintain a comfortable typing speed.
- Practice regularly.
## Manual Testing Checklist

- [ ] Complete a short typing test and review the score.
- [ ] Check how incorrect characters affect accuracy.
- [ ] Restart the session and verify its statistics reset.

### Test Notes

Record the observed result and any reproducible issue after running the tests.
